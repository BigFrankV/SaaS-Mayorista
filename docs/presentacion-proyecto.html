Aislamiento Multitenant

Cada tenant (distribuidora) tiene datos 100% aislados via TenantContext (ThreadLocal). El tenant_id se extrae del JWT y se inyecta automáticamente en cada consulta JPA.

🛡️

Seguridad por Capas

JWT con access + refresh tokens · Rate limiting por IP · Lockout por intentos fallidos · Token blocklist en Redis · Filtro CORS configurable · Roles: ADMIN, VENDEDOR, BODEGUERO, CONTADOR

⚡

Transacciones Críticas

Las ventas usan SELECT FOR UPDATE (pesimistic locking) para evitar race conditions en el descuento de stock cuando múltiples cajeros venden simultáneamente.

📋

SDD — Spec Driven Development

Cada cambio sigue un flujo estructurado: Exploración → Propuesta → Especificaciones → Diseño → Tareas → Implementación → Verificación. Sin saltos, sin ambigüedad.

🔍

CodeGraph Analysis

El agente usa CodeGraph para entender la arquitectura, explorar dependencias, calcular impacto y navegar el código antes de escribir cualquier línea.

🔄

Review & Judgment Day

Cada cambio pasa por revisión automatizada con múltiples lentes (riesgo, resiliencia, legibilidad, confiabilidad) y un adversarial review de dos jueces ciegos.

🧠

Engram Persistent Memory

El agente recuerda decisiones, bugs, descubrimientos y preferencias a través de sesiones usando memoria persistente. Arquitectura, decisiones técnicas, todo queda registrado.
